**Integrated Expense, Attendance, Grading and Billing Manager**

About the Project

The Integrated Expense, Attendance, Grading and Billing Manager is a menu-driven Python application that combines four management systems into one program. It helps users manage expenses, record student attendance, calculate grades and generate bills.

The project is developed using basic Python concepts such as functions, lists, loops, conditional statements and match-case.

Features

1. Expense Management

Add new expenses.

Categorize expenses.

Calculate total expenses.

View category-wise expense summaries.

Identify the highest and lowest expenses.

2. Attendance Management

Record student attendance.

Store roll numbers and student names.

Calculate attendance percentage.

Display attendance eligibility status.

3. Grading Management

Enter marks for five subjects.

Calculate total and average marks.

Assign grades based on performance.

Display pass or fail status.

Generate individual report cards.

View class performance summary.

4. Billing Management

Create bills for customers.

Add multiple items to a bill.

Calculate subtotal and discount.

Apply 18% tax.

Display the final bill amount.

View previously generated bills.

5. Reports

View expense summaries.

View attendance summaries.

View class performance summaries.

View billing records.

Technologies Used

Programming Language: Python

Concepts Used: Functions, Lists, Loops, Conditional Statements, Match-Case, Exception Handling and List Operations.

Editor: VS Code / Any Python Online Compiler

Installation Steps

Download or clone this project repository.

Make sure Python 3.10 or above is installed.

Open the project folder in VS Code or any Python editor.

No additional libraries are required because the program uses Python's built-in features.

How to Run

Open the project folder.

Open the Python file in your editor.

Run the following command in the terminal:

python main.py

The main menu will appear.

Enter the corresponding number to select a module.

Follow the instructions displayed on the screen.

Select Exit to close the program.

Important Notes

The application is menu-driven and runs in the terminal.

Data is stored temporarily using Python lists.

The records are not permanently saved and will be lost when the program is closed.

Python 3.10 or above is recommended for match-case support.
